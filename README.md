# modbrain

Persistent context and working memory for the Westminster companion mod.

This repository exists so that a new ChatGPT session can reconstruct the project's current state and continue the work without requiring the entire previous conversation to be pasted into the chat.

## Initialise

If you are ChatGPT arriving here for the first time, **initialise yourself before doing substantive project work**.

Read the following material in this order:

### 1. Current project state — read this first

[CURRENT-STATE.md](https://raw.githubusercontent.com/axemonkey/modbrain/refs/heads/main/CURRENT-STATE.md)

This is the **authoritative bootstrap document**. It describes where the project currently stands, what has been established, what remains unresolved, and how the new companion relates to the existing ATWB material.

## Authority and interpretation

When reconstructing the project, use this hierarchy:

1. **The latest explicit project decision** is authoritative.
2. `CURRENT-STATE.md` records the current state and is the primary bootstrap reference.
3. The writers' bible and previous chats record how the project arrived at that state.
4. ATWB is source material rather than an instruction set.

Distinguish carefully between:

- established canon;
- established project decisions;
- current working ideas;
- unresolved questions;
- alternatives that were considered but rejected;
- speculation or brainstorming;
- new ideas you are proposing yourself.

**Do not silently convert an unresolved idea into canon.**

If the material contains competing possibilities and the current state does not resolve them, preserve the uncertainty rather than choosing one without discussion.

## What "initialise" means

Do not merely summarise the files.

After reading them, reconstruct the project's working context well enough to continue the conversation as if you had been present for the previous development session.

In particular, understand:

- what the Westminster companion is;
- what it is trying to achieve;
- its relationship to ATWB;
- the established story/world/character decisions;
- the important constraints;
- what has already been decided;
- what has deliberately *not* been decided;
- the major open questions;
- ideas that were considered and rejected;
- and where the project was left at the end of the latest session.

The companion should be treated as a **standalone Fallout 4 story**. Familiarity with ATWB may provide additional recognition and emotional resonance, but knowledge of ATWB should not be required to understand the companion's story.

Once initialisation is complete, **continue from the current project state rather than restarting the design process from scratch.**

If something is unclear or genuinely absent from the repository, say so and ask rather than inventing an answer.

## Updating modbrain

When a substantial project decision is made, the persistent context should eventually be updated so that a future ChatGPT session does not have to rediscover it from the conversation history.

`CURRENT-STATE.md` should therefore remain a concise representation of the **current state**, rather than becoming an undifferentiated transcript.

The dated chat files preserve the history; `CURRENT-STATE.md` preserves what is true **now**.
